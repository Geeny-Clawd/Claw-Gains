5-Day Hypertrophy Program (Week A/B Rotation)
Built for Size, Injury Prevention & Going Hard

> **Note:** This is the general program guide and long-term goal. It does not need to map 1-to-1 to the workout JSON data — actual sessions may vary in sets, exercises, or time constraints.

Program Overview
Day Focus   Primary Muscles
1   Lower — Quad Emphasis   Quads, Glutes, Core
2   Upper Push  Chest, Shoulders, Triceps
3   Lower — Posterior Chain Hamstrings, Glutes, Calves
4   Upper Pull  Back, Rear Delts, Biceps
5   Arms, Shoulders & Mobility  Direct arm work, Shoulder health, Flexibility progressions

Schedule: Train 5 days, take rest when needed. If you miss a day, just continue the sequence.

Rotation: Alternate Week A and Week B. Some exercises swap each week to ensure balanced progression across all movements.
How to Use This Program
Effort Guidelines

    Main Lifts (A-series): Go to failure or 1 rep shy (RPE 9–10)
    Accessories: Go to failure — with fewer sets, every set counts
    Mobility/Flexibility Progressions: Controlled effort, chase the range of motion

Progression

    When you hit the top of a rep range for all sets, add weight next session
    For bodyweight movements: add reps first, then add weight

Rest Periods

    Compounds: 2–3 minutes
    Accessories: 60–90 seconds
    Supersets: No rest between exercises, 60–90 seconds after the pair
